# Portal Embaixadores — Bia Bogossian 55024

Site onde cada embaixador da campanha cria a própria conta (e-mail/senha)
e cadastra as pessoas que converteu em voto: nome, probabilidade real de
votar (1 a 5) e município do RJ.

Este repositório é o braço "de entrada de dados" da campanha. Os dados
alimentam o painel administrativo da **Plataforma Campanha**
(dashboard + gestão de embaixadores), publicado em
[`acervo-fred/plataforma-campanha`](https://github.com/acervo-fred/plataforma-campanha)
— os dois sites compartilham o mesmo projeto Firebase (`bia2026-campanha`),
ver `js/config/firebase-config.js`.

HTML/CSS/JS puro, sem framework, sem build.
